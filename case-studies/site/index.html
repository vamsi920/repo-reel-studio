Benchmarks · one module at a time

Measured against Devin, with the losses left in.

We give NeoDevEx and Devin the same real jobs on the same code, check the results against the code itself, and publish what happened, including where we lose. Each study opens with a two-minute summary; the full details for engineers are underneath.

Studies

  • Codebase guides vs Devin'sPublished

    We tested the guides our AI writes to explain a codebase against Devin's, on 75 questions checked against the code. Ours answered more correctly (63% vs 52%) and made things up far less often (3% vs 23%).

  • Automations vs DevinPublished

    We gave NeoDevEx and Devin the same unattended jobs on a test codebase. We now pass all 10 tests we could run and Devin passes 7, but Devin is still faster and always on.

  • Chat agent vs DevinPublished

    Six real coding tasks for both. Ours now gets 98% of facts right (Devin 94%) and costs $0.21 a task against Devin's $0.38. Devin is still faster.

  • AI costs vs DevinPublished

    We cut our AI bill per task by about a third with no drop in quality. Investigating the same bug report cost us $0.017 and Devin $0.22.

  • Running our own AI modelPublished

    We ran free AI models on a computer we rent by the hour instead of paying Google per use. Quality now matches Gemini, but it is slower and only saves money if the computer is kept busy.

  • Setting up at a bankPublished

    Our setup assistant learned a simulated bank's tools and rules and connected its private code system in every final run, up from none at first. It no longer claims connections it never made, but results still vary run to run.
