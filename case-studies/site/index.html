Benchmarks · one module at a time

Measured against Devin, with the losses left in.

Each study runs NeoDevEx and Devin on the same public repositories at the same commits. We ask questions whose answers we first checked in the code, grade both tools without knowing which is which, and publish every verdict, score and our own outputs.

Studies

  • Knowledge Transfer docs vs Devin WikiPublished

    75 code-verified questions on ky, flask and hono. Docs-only reading 62.7% vs Devin 52.3%; repository Q&A 81.3% vs 71.3% with 2.7% false claims vs 22.7%; 460 files cited vs 315, 0 uncovered questions vs 2.

  • Automations vs DevinPublished

    Twelve automations, four rounds, one real repository. NeoDevEx went from 2/7 to 10/10 passing after 54 fixes the study and two code audits found: GitHub, CI and PR triggers; schedules within 2 s; repo-scoped triggers; verified delivery; run recovery; spend and rate limits; failure alerts; webhooks set up in the app; background running. Devin passes 7/10 and goes deeper on the default model; with Gemini 2.5 Pro our reviews match it on correctness and show executed proof.

  • Token costs vs DevinPublished

    154 real agent runs on Gemini 2.5 Flash, tokens as reported by the provider. The Layman integration as shipped saved 0 tokens on a fresh install; moved to where tokens go (skills index, automation contract), the same tasks use 36% fewer tokens and cost 35% less with the same pass rate (17/20 vs 16/20). Same triage task: Devin $0.22, NeoDevEx $0.017.

  • Self-hosted model vs frontierPublished

    Four studies re-run on one rented GPU ($1.69/h) serving open-weight Qwen3-Coder-Next instead of Gemini: $4.80 billed, at least $10 less than what Gemini charged in the original runs, almost all of it in the KT docs study. Best chat test score yet (93% vs 81%) and 14/15 token-bench tasks, but weaker explanations (74% vs 83%), KT Q&A level with Devin rather than Gemini, 8/10 automations with two pushes to main, and about 4x slower.
