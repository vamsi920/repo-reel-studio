Chat agent · October 2026

Our chat agent now matches Devin on code questions and tests, for 45% less.

We gave our chat agent and Devin the same six tasks on three open-source codebases: explain how some code works, or write tests for it. We checked every answer against the code, because developers only trust an assistant that does not guess.

  • 98%of facts right in our explanations, up from 27% (Devin 94%)
  • 18 / 18of our test runs caught every bug we planted (Devin 2 / 2)
  • $0.21our cost per task (Devin $0.38)
  • 59%less AI usage (what AI providers bill us for) per task

What we found

  • At first our agent answered from memory and made things up.
  • Short standing instructions to read and quote the real code, plus Google's newer Gemini 4 Argon AI model, fixed that.
  • Its tests now pass on the real code and fail when we break it.
  • Reading less and writing shorter notes cut cost from $0.44 to $0.21 a task, with no loss in accuracy.

Where we still fall short

  • Devin is faster: 78 seconds per task against our 129.
  • Graded by hand instead of by AI, Devin's explanations score 100%, slightly ahead of our 98%.
  • The AI model's price doubles on 1 December, putting our cost near $0.42 a task, about Devin's.

Bottom line: We now match Devin on quality and cost less today. Speed and the coming price rise are the gaps to close.

Full technical write-up, for engineers

Module 03 · Chat agent · 2026-10-12 to 2026-10-13

We asked both chat agents the same questions about real code, then checked every answer against the source.

Six tasks on three open-source repositories (flask, hono, ky) at pinned commits: three "explain how this works" questions and three "write tests for this behaviour" requests. Answers were scored against fact checklists written from the source before any answer was read. Tests counted only if they passed on the real code and failed when we planted a bug. At the start, NeoDevEx answered from memory and wrote tests that missed planted bugs (27% and 56%). We fixed the instructions every conversation starts with, moved the default model to Gemini 4 Argon, and turned on Layman's output compression for it. NeoDevEx now scores 98% on explanations (Devin 94%), and all 18 of its test runs catch every planted bug (Devin 2 of 2). It costs $0.21 a task to Devin's $0.38. Devin is still faster: 78 s of its own "worked" time against our 129 s median wall-clock.

Why it works

  • Reading. Every file the agent prints is resent on every later call. Printing flask's 1,625-line app.py once added about 70k tokens to each call after it. Locating with grep -n and viewing line ranges cut input 35%.
  • Writing. Layman's caveman style drops preamble, plan narration and restated tool output between calls, but never code, tests, commands or the final answer's facts. Output fell 25%, and the shorter history shrank later inputs too.
  • Thinking. With terse narration, medium thinking was enough: thinking tokens fell another 52% with no accuracy change.

Where Layman does not help

  • On Gemini 2.5 Flash an output-brevity directive lowered task success (token study, rounds 1–2). The app only sends the output style to frontier-tier models, and medium thinking only to Gemini frontier models, where it was measured.
  • Compressing the fixed prompt further saves little on Argon: it is cached after the first call.

Where we lagged, and what we changed

Gaps the study found

  • fixedAnswering from memory. On the Flask question the base agent made 2–3 calls and described an older Flask: a RequestContext that no longer exists, the signal in the wrong method, after_request "typically skipped". Devin opened every function and ran a script.
  • fixedNot opening the code at all. One ky answer said it could not inspect the files "due to tool limitations" and invented a header.
  • fixedTests that don't catch bugs. Base tests passed, but missed 1–2 of 3 planted bugs: they checked that something ran, not the order or the arguments.
  • fixedWrong environment. Rules 1 runs created new virtualenvs, ran tox with a newer pytest, or ran npm install, then "fixed" the resulting failures by editing conftest.py or package.json.
  • fixedTests that only pass on the agent's own edits. The test passed in the agent's tree but failed on a clean checkout, because it relied on a changed package.json, conftest, deleted helpers or even ky's source.
  • fixedNo file at the end. One run spent its budget and never wrote the requested test file.
  • fixedModel generation. Gemini 2.5 Flash still made version mistakes with every rule in place (a RequestContext that no longer exists). The default is now Gemini 4 Argon.
  • fixedCost on the stronger model. Argon cost $0.44 a task, more than Devin. Lean reading, Layman output style and medium thinking brought it to $0.21.
  • fixedBlank model in Settings. A model missing from the agent-server's model list (Gemini 4 Argon is) showed as an empty field, and saving dropped it. The picker now keeps the current model.

The fix: working rules on every conversation

A short <WORKING_RULES> block now starts every NeoDevEx conversation's system prompt (src/lib/agent/working-rules.ts). It asks for what Devin did: read the checked-out code, cite path:line, confirm behaviour by running it, use the project's own environment, prove each test fails when the behaviour breaks, and clean up before finishing. It is about 470 tokens. Frontier models also get Layman's output style (about 115 tokens). Both sit in the cached prefix.

Questions: answer from the checked-out files, not memory. Open every function you describe, cite path:line, confirm order by running it. Read efficiently: grep -n, then view only the line ranges you need. Find how the project runs (ls -a); use its own env. No new virtualenv, tox or npm install; never install this project from a registry. Always create the requested file. Never edit other files to make it pass. Tests must fail when the behaviour breaks: break the source, see it fail, restore, see it pass. Report real output. Before finishing: git status --short, undo anything not asked for, re-run the test on the clean tree.

A paraphrase. The exact text is in the source file.

Where Devin is still ahead

  • Speed. Devin reports 52–104 s of work per task. Our median is 129 s wall-clock (76–212 s by task), including environment discovery and each test's prove-it-fails run.
  • Flask teardown detail. F1 is the one explain task where Devin scored higher (100% vs 94%): our answers name the teardown order but not that errors are collected.
  • Hosted and always on. Devin runs in its cloud; NeoDevEx runs where it is installed.

Where we are ahead now: explanation accuracy (98% vs 94%), every test run proven against planted bugs (18 / 18), and 45% cheaper per task ($0.21 vs $0.38).

How we tested

  • Repositories at pinned commits: pallets/flask 258d68b6, honojs/hono 24547a6e, sindresorhus/ky e0fcf78, the same three used in the KT docs study. Each run got a fresh copy with dependencies installed.
  • Same prompt on both products. Devin's prompts added the repository and commit to check out, and "do not push or open a pull request" on test tasks.
  • NeoDevEx ran on OpenHands SDK 1.42.1 (the version the app ships). The agent was built from the exact settings the app sends when it starts a conversation, dumped by a test that calls the app's own request builder. Browser tools were off. Gemini 2.5 Flash and 2.5 Pro for the early rounds, Gemini 4 Argon after the default switch.
  • Explain answers were scored by a blind judge (Gemini 2.5 Pro, not told which agent wrote the answer) against fact checklists written from the source before any answer was read. We hand-graded 10 answers first; the judge's scores differed from ours by 0.05 on average.
  • Tests were mutation-graded: run on the real code (must pass), then once against each of 3 planted bugs per task (should fail). A test that fails on the real code scores 0.
  • Costs: Devin from its usage history; NeoDevEx from the SDK's own token and cost metrics, which match Google's list prices on 2026-10-13 (Argon: $2 / $10 / $0.10 per million input / output / cached tokens). Argon's price doubles on 2026-12-01, which would put our cost near $0.42 a task, about Devin's.

What could skew this

  • Small samples: Devin ran each task once, and NeoDevEx 1–3 times per variant. A single run can swing a task's score a lot.
  • Devin's H2 was not run (out of credit), so its test score covers two tasks.
  • The rules were written in response to these six tasks and re-measured on them. They are general (read the code, use the project's environment, prove the test), but a fresh task set would be a stronger test.
  • The judge is a model (Gemini 2.5 Pro). Its K1 score for Devin (83%) is lower than our hand grade (100%). With our hand grade, Devin's explain average is 100%, ahead of our 98%.
  • Devin chose its own model; we compared our model choice against it. The rules, Layman and model changes are what we measured; we cannot separate Devin's model from its agent.
  • NeoDevEx time is wall-clock; Devin's is its own "worked for" figure, which may exclude setup.
